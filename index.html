Study by the skills Microsoft currently measures

The curriculum is aligned to the Microsoft PL-300 study guide skills measured as of April 20, 2026. The official weighting places Prepare the Data, Model the Data, and Visualize and Analyze Data at 25–30% each, and Manage and Secure Power BI at 15–20%.

25–30%

Module 1 — Prepare the Data

Learn how Power BI connects to data, profiles its quality, transforms it in Power Query, and controls loading and refresh so the resulting model is accurate and efficient.

6 focused concepts → 25–30%

Module 2 — Data Modeling

Learn how fact and dimension tables, grain, relationships, date roles and calculated objects work together to create a semantic model with predictable filtering and strong performance.

5 focused concepts → Core modeling skill

Module 3 — DAX & Filter Context

Learn how DAX evaluates measures by understanding filter context, row context and context transition, then apply those ideas to iterators, filter modifiers, time intelligence and reusable calculations.

6 focused concepts → 25–30%

Module 4 — Visualize & Analyze Data

Learn how to choose and configure visuals for the analytical question, control filtering and navigation, design accessible reports, and use analytical, AI and specialized reporting features appropriately.

Module 5 — Power BI Service & Security

Frequently asked

Before you start

Will my progress sync?

No. Progress is stored in localStorage on the browser/device you use. Changing browser, clearing site data or switching devices can make progress unavailable.

Is the mock score official?

No. The site shows a raw study percentage. Microsoft's certification exam uses scaled scoring; use the mock to diagnose strengths and weaknesses.

Is this an exam dump?

No. Questions are original study questions designed around tested skills and common decision patterns, not copied live exam content.
